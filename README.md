## 范围与完整性

- 已按本机原始记录导出可读取的用户/助手正文，包括普通会话与已归档会话；压缩存储的历史日志已解压读取。
- 续接会话已按 history_base 指定的继承边界恢复前序消息，避免仅读取当前日志而遗漏历史。
- 当前项目之外的旧项目按工作目录归类；同名的 Desktop\1 与 Documents\1 分别保存，避免混淆。
- 未绑定项目的本地聊天和当前可见的 ChatGPT 聊天放入“未归属项目”，不擅自并入其它项目。
- 部分 ChatGPT 助手回复仅提供引用标记，其正文并未获取。对应文件逐条标记，不将该部分称为完整备份。
- 某些旧会话本地只记录用户消息或没有可读正文，相关缺口已注明。
- 导出的是文本记录；图片、音频等附件二进制不包含在 Markdown 中。
- 已排除 9 个内部自动审查/子代理会话；没有修改原始会话数据库和日志。

每个项目文件均包含对话目录、原始标题、时间、会话 ID、逐条正文和缺口说明。
